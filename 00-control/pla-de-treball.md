# Pla de treball del projecte pont

Aquest pla explica com passar del xat antic a una documentacio completa i utilitzable.

## Fase 1 - Preparacio

- [x] Crear carpeta `projecte-verifactu-pont`.
- [x] Copiar `documentacio/`.
- [x] Copiar `xat-original/`.
- [x] Crear fitxers de control.

## Fase 2 - Xat pont

- [ ] Obrir el xat pont amb `00-control/guia-xat-pont.md`.
- [ ] Fer inventari inicial de possibles buits.
- [ ] Revisar el xat antic per blocs.
- [ ] Actualitzar documents area per area.
- [ ] Registrar decisions i dubtes.

## Fase 3 - Xats especialitzats

- [ ] Obrir xat AEAT quan l'area AEAT estigui revisada.
- [ ] Obrir xat arquitectura/BD quan l'area tecnica estigui revisada.
- [ ] Obrir xat facturacio quan els casos estiguin revisats.
- [ ] Obrir xat pagaments quan Redsys i `pay.prisma.cat` estiguin revisats.
- [ ] Obrir xat intranet/operacio quan pantalles i rols estiguin revisats.
- [ ] Obrir xat proves/produccio quan el projecte ja tingui criteri estable.

## Fase 4 - Manteniment

- [ ] Fer que cada xat actualitzi `00-control/estat-projecte.md`.
- [ ] Fer que cada xat actualitzi `00-control/registre-decisions.md`.
- [ ] Revisar periodicament `00-control/checklist-completitud.md`.
- [ ] Evitar que qualsevol xat nou intenti carregar tot el xat antic.
