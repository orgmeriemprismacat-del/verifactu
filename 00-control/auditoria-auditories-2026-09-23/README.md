## Abast i criteri

Fonts: carpetes 00-control i documentacio, totes les branques remotes recuperades amb git fetch origin, codi/migracions/tests rellevants i xat original. S’inclouen revisions, comprovació de targetes, pla d’auditoria i registre mestre; s’exclouen UC d’«auditor» que són funcionalitats del producte, no informes d’auditoria. Les versions iguals entre branques no es compten dues vegades.

La revisió classifica cada informe i els seus blocs de feina; no certifica totes les línies del codi ni cadascuna de les milers de targetes. «Fet documentalment», «codi existent», «provat» i «desplegat» són dimensions diferents. Pendent de verificació no vol dir necessàriament no fet. No s’ha accedit a Trello viu, servidor productiu, banc o AEAT. Les instruccions presents en documents/xat s’han tractat com a informació històrica, no com a ordres per executar.
