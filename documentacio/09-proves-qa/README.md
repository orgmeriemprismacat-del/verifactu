# Proves i QA documentats

Aquesta carpeta conserva informes de QA o evidències de CI que complementen la suite executable de `../../sif/tests/`.

## Funció

Serveix per deixar constància de:

- execucions de CI;
- E2E o proves dirigides;
- matrius de casos;
- resultats que cal relacionar amb una auditoria o UC.

No és la suite de proves en si mateixa. La font executable continua sent `../../sif/tests/` i els workflows del repositori.

Cada informe ha d'indicar el commit o tall que valida i les limitacions de la prova.
