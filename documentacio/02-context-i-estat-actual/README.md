# Context i estat actual

Aquesta carpeta descriu el **punt de partida (AS-IS)**: sistemes, canals, bases de dades, taules i relacions que existeixen abans o durant la migració al SIF.

## Funció

Serveix per entendre:

- què fa avui la web/ecommerce;
- què fa la intranet;
- quines dades viuen als sistemes legacy;
- quines dependències cal mantenir temporalment;
- quines responsabilitats han de migrar al SIF.

Aquesta carpeta no defineix per si sola el disseny final. El TO-BE és a `../04-estat-final/`; la diferència entre tots dos és el GAP que ha d'alimentar implementació i proves.
