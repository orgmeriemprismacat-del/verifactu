# Índex, pla i cobertura

Aquesta carpeta conté els documents que expliquen **com s'organitza el projecte**, quina cobertura documental existeix i com es relacionen plans, UC, implementació i Trello.

## Hi trobareu

- document mare del projecte;
- pla documental i d'auditoria;
- matrius de cobertura;
- informes d'auditoria documental;
- pla tècnic d'implementació;
- mapa Trello ↔ repositori;
- registre mestre de cobertura funcional/implementació/documentació;
- rescats o reconciliacions documentals datades.

## Regla de lectura

Els documents sense data o marcats com a registre mestre són els candidats naturals a ser vius. Els fitxers amb sufix de data són **snapshots** i s'han de conservar com a traça.

La cobertura documental no acredita implementació. Per comprovar estat executable cal anar a `../../sif/`, proves i evidències.
