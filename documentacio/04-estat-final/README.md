# Arquitectura i estat final objectiu

Aquesta carpeta descriu el **TO-BE** del projecte: model de BD, sistema, pantalles, operació, diagrames, casos d'ús, traçabilitat, mapa de components i auditories de cobertura.

## Important

“Estat final” significa **disseny objectiu**, no “ja desplegat”.

Per saber si una peça del disseny existeix realment cal contrastar:

- `../../sif/`;
- integracions a codi legacy/candidat;
- `../../sif/tests/`;
- CI;
- `../09-evidencies/` i `../09-proves-qa/`.

## Documents clau

- model BD;
- estat final del sistema i pantalles;
- catàleg de casos d'ús;
- diagrames generals;
- matrius de traçabilitat;
- mapa de components;
- auditoria de `codi-drive`;
- matriu de transformació funcional;
- auditoria de fitxes i buits;
- superfície executable.

El criteri és mantenir la diferència AS-IS / TO-BE / GAP explícita.
