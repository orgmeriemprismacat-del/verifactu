# Compliment AEAT i declaració responsable

Aquesta carpeta agrupa la documentació de compliment del SIF davant AEAT: documentació tècnica/organitzativa, declaració responsable, annexos, responsabilitats i vistiplau tècnic.

## Regla principal

Un esborrany documental no acredita que la versió estigui preparada per signar o producció. Abans d'activar una versió cal contrastar:

- versió exacta del codi;
- configuració i certificat/apoderament;
- model fiscal i registres;
- PDF/QR/XML o equivalents;
- proves i preproducció;
- evidència;
- decisió formal d'activació.

Els fitxers Word/PDF derivats no han de convertir-se en una font paral·lela que contradigui el document canònic.
