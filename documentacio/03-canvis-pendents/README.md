# Canvis pendents i contractes de transició

Aquesta carpeta recull el **GAP** entre l'estat actual i l'arquitectura objectiu: fluxos a migrar, pantalles, Redsys, contractes API, cues, procediments i checklist de producció.

## Com utilitzar-la

Cada canvi pendent hauria de poder vincular-se a:

```text
requisit / UC
→ targeta
→ codi o migració
→ prova
→ evidència
→ actualització documental
```

Quan una feina ja està implementada i verificada, el document pendent s'ha d'actualitzar o marcar com a tancat; no s'ha de mantenir una falsa llista de pendents.

Els fitxers datats són snapshots i no prevalen sobre una versió viva posterior.
