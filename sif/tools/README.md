# Eines de suport del SIF

Aquesta carpeta conté eines de desenvolupament o documentació que donen suport al projecte però no formen part del flux fiscal principal en producció.

## Eines actuals

- `functional-card/`: generació i validació mecànica de fitxes funcionals.

## Regla

Una eina pot ajudar a preparar manifests, validar estructura o reduir errors manuals, però no converteix automàticament una fitxa en especificació validada ni substitueix l'auditoria contra codi, dades, decisions i proves.

Cada eina ha de tenir el seu README amb abast, autoritat, ús, limitacions i efectes.
